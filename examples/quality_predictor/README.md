# Expo West inference example

This example contains eight regions from Expo West before reacquisition:

- `expo_west_sample_inputs.npz`: prepared input features for the Quality Predictor.
- `expo_west_sample_scores.npy`: reference regional predictions in the same order.

These example arrays are provided under the Apache License 2.0 in
[LICENSE](../../LICENSE). They contain no original photos or backbone weights.
The example is for checking inference, not reproducing an evaluation table.
See the [quick start](../../docs/quickstart.md) and
[asset manifest](../../configs/quality_predictor.release.json).
