# Security reporting

A dedicated private reporting channel has not been configured. Issues and
Discussions are visible to repository readers; neither is a private inbox.
Until a private channel is available, post only a request for secure contact,
without exploit details, credentials or identifying data.

Never include access tokens, SDK keys, signing material, aircraft identifiers,
private locations, images or flight logs in that request. Share a minimal
reproduction only after a private reporting channel has been agreed.

The source repository does not require production credentials. Workstation
tokens, backbone weights and runtime data remain outside Git. Downloading or previewing a
generated mission does not authorize flight.
