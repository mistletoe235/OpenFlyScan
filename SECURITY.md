# Security reporting

A private maintainer contact must be set before public release. Do not publish
access tokens, SDK keys, signing material, aircraft identifiers, private locations,
images or flight logs in public issues. Report a minimal reproduction privately
once the project's reporting address is available.

The source repository does not require production credentials. Workstation
tokens, backbone weights and runtime data remain outside Git. Downloading or previewing a
generated mission does not authorize flight.
